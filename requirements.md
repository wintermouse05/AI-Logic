
# Library requirements
To run the code in this directory, you need the following Python library:

- `pygame`: Used for the graphical user interface (GUI) in `pygame_gui.py`.

## Installation

You can install the required library using pip:
```bash
pip install pygame
```

## Notes
- All other imports are either standard Python libraries (such as `os`, `sys`, `random`, `dataclasses`, `heapq`, `math`, `copy`, `threading`, `queue`) or are local modules within this project.
- Python 3.7 or higher is recommended for best compatibility.
- No additional external dependencies are required.
